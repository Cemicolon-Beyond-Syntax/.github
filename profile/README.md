# Cemicolon — Beyond Syntax

> **Learn to code. Understand how it works. Build beyond the syntax.**

Welcome to **Cemicolon** — a space for learning, building, and exploring programming and computer science beyond simply writing code.

We believe programming is not just about remembering syntax or following tutorials. It is about understanding **why things work, how systems fit together, and how to turn ideas into real software.**

---

## 🚀 What You'll Find Here

This organization contains the source code, examples, projects, and experiments behind the **Cemicolon** learning journey.

### 📚 Tutorials & Learning

Practical codebases that accompany our tutorials and help turn concepts into something you can actually run, modify, and experiment with.

### 🛠️ Projects

Real-world projects built to explore software development, architecture, problem-solving, and different technologies.

### 🧪 Experiments

Small experiments and explorations used to understand technologies, concepts, and ideas beyond the surface level.

### 🌱 Learning in Public

Software development is a continuous journey. This organization will evolve as we learn, build, experiment, and discover new ideas.

## 🎯 Beyond Syntax

Learning a programming language is only the beginning.

At Cemicolon, we want to explore the bigger picture:

```text
Syntax
  ↓
Programming
  ↓
Problem Solving
  ↓
Software Engineering
  ↓
Computer Science
  ↓
Understanding How Things Work
```

The goal isn't simply to write more code.

**The goal is to understand what we're building and why it works.**
